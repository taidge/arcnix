# 界面原语与交互约定

## 设计目标

主窗口承担导航、文件浏览和传输状态。创建、编辑、导入、认证等需要输入并提交的任务使用独立模态对话框，不将表单插在文件区上方。不以新增常驻按钮作为每个新功能的默认入口。

输入框聚焦只改变原有 1px 边框的颜色，不叠加外层 outline、阴影或粗边框；鼠标和键盘聚焦保持一致。按钮键盘焦点使用内侧细线，保留可辨识的焦点状态。

文件、系统软件、资源概览和系统日志分别使用独立工作区。底部“操作日志”记录客户端操作，与远程“系统日志”明确区分；提示中的查看入口应切换到实际承载日志的页面。

默认语言为英语，支持从 Settings 实时切换简体中文。产品字符串集中在 `assets/translations.tsv`，不翻译用户命名的站点、分组、路径和远程输出。主题为 Dark／Light，使用统一颜色变量和语义化选中状态。

## 信息层级

| 区域 | 内容 | 不承载的内容 |
| --- | --- | --- |
| 顶栏 | 左侧品牌，右侧模块标签，最右侧为当前服务器、SSH 状态和统一连接操作 | 密码常驻输入、服务器编辑表单、额外的第二层连接工具栏 |
| 侧栏 | 搜索、分组与服务器导航、新建和导入入口、底部 Settings | 常驻编辑/删除按钮、分组名称和导入路径表单 |
| 文件区 | 对称的本地/远程面板、路径、目录列表和选择相关操作 | 与服务器配置无关的表单 |
| 底部活动区 | 传输、操作日志两个视图 | 同时展开的多层工具条和日志卡片 |
| 模态层 | 单一任务的标题、字段、就地反馈、取消和主要提交动作 | 与当前任务无关的工作台工具 |

## 视觉原语

- 以统一间距刻度组织页面：4px 基础单位，控件间距通常 8px，区域留白 16–24px。控件高度、边框、圆角、字号与焦点环由统一 CSS 类控制。
- 按钮区分主要动作、普通动作、无边框的轻量动作、图标动作和危险动作。一个任务只突出一个主要动作。不要为每个动作重复不同的填充色和边框。
- 关闭统一使用 Sapid `CloseButton`，导航、刷新、更多、筛选、展开/收起、队列取消/重试等通用工具动作使用 `ActionIcon`。图标按钮不含可见文字，必须有准确的中文可访问名称和悬停/键盘提示。
- 保存、连接、上传/下载、新建等需要明确意图的主要动作保留文字；文字前需要图标时使用同一套 SVG，不拼接箭头、加号等字符。所有图标采用 24×24 画布、统一线宽和 16px 显示尺寸，按钮使用 30px 命中区域。
- 表单标签始终可见，字段上下排列或按语义组成两列；端口使用紧凑宽度，主机占剩余宽度。
- 私钥路径保留手动输入，并在同一行提供 Browse…；打开系统文件选择窗口，成功回填，取消保留原值。
- Settings 使用独立工作区，分为 General、Appearance、Files 和 Monitoring，不增加顶部业务标签。修改成功保存后才应用，错误就地显示。
- 列表以行与轻量分隔线组织，不为每行再嵌一张独立卡片。选中、悬停、焦点、禁用状态各自有明确且统一的表现。
- 双栏面板的路径、筛选、列标题、底部选择状态采用一致的顺序。字号与列宽一致。目录名可以打开目录，普通文件不出现不可用的“打开”按钮。
- 左右文件栏间使用 10px 命中区和居中的细分隔线，可拖动；比例按服务器单独保存，切换与重启恢复，窄窗口仅调整当前展示，不覆盖已保存偏好。
- 所有滚动区统一使用 6px 滚动条，隐藏箭头，轨道透明；滑块低对比度，悬停时加深。
- 文件冲突采用统一模态，展示两边元数据、覆盖／跳过和明确应用范围。默认跳过，关闭或取消会结束队列；未来连接规则按服务器和方向保存，并有重置入口。
- 名称、大小、修改时间列标题直接承担排序，不再并列“排序字段”和“升/降序”的循环按钮。
- 筛选是按需展开的工具，不让每个面板始终承载一整排辅助按钮。

## 服务器与分组

- 新建/编辑服务器使用同一种模态原语，标题区分“新建服务器”和“编辑服务器”。取消不保存，不影响现有连接。
- 认证方式使用可直接选择的“密码/私钥”分段控件；只有私钥方式显示私钥字段。分组使用明确的选项列表，避免“点击切换到下一项”的隐式选择。
- 每个服务器条目由“选择服务器”和独立的“更多操作”按钮组成；不嵌套按钮。
- `…` 默认不显示，鼠标悬停条目、键盘焦点进入条目或菜单已打开时显示。隐藏状态保留可聚焦性，支持键盘用户通过 Tab 发现菜单。
- 编辑和删除属于菜单指向的服务器，不依赖另一个全局选中状态。删除先打开包含具体服务器名称的确认对话框。
- 分组新建/改名和 SSH 配置导入也使用相同的对话框结构，避免长期占据侧栏。

## 文件、队列与反馈

- 文件/目录选择和打开目录是两个明确动作，选择状态不依赖仅可见的颜色。
- 上传和下载放在各自源面板的操作区。未连接、无选择或目录尚未成功读取时，动作必须有适当的禁用状态或明确反馈。
- 新建目录和重命名通过文件面板的更多菜单进入对话框，不共享一条悬空的“新建/重命名名称”输入框。
- 队列暂停只停止后续调度，不暗示当前传输被暂停。取消、失败、完成保留其原有语义。
- 表单验证错误就地显示，保留输入。系统与网络错误写入日志；当前任务不能仅依靠用户切换日志视图才知道失败。
- 操作日志与传输使用同一活动区；服务器资源统一使用顶部“资源概览”，避免将多个低优先级面板垂直叠在主要文件区下方。

## 桌面宿主的交互边界

当前 Glory Wry `0.7.0` 支持普通 View、Button、Input、Check、键盘命令、输入提交、焦点操作和 inert 语义，但不支持高级 Layer、Select、focus_scope 和 menu metadata。因此使用 Rust 构建的普通控件、命名分组与 CSS 定位实现对话框/弹出操作列表，不调用宿主明确拒绝的组件能力。

Wry 当前不支持默认 Graphic 图标绘制。`icons.rs` 通过 Sapid 的图标插槽填充装饰 SVG mask，保留 `CloseButton`/`ActionIcon` 的按钮、禁用和焦点行为，颜色继承 currentColor。图标资源位于 `assets/icons`，构建时嵌入，不加载外部资源；不直接使用文字标签冒充图标。

- `Escape` 通过祖先 `keyboard` 监听与 `KeyboardCommand::Dismiss` 处理，优先关闭当前菜单/对话框。
- 路径栏 Enter 通过输入的 `commit` 事件处理。避免同时添加全局 Submit 与字段 commit 导致重复提交。
- 对话框出现时，使后台区域 `Semantics.inert = true`；遮罩不进入正常 Tab 顺序；将初始焦点移入对话框，关闭后恢复到有效触发控件。
- 对话框使用 `Role::Dialog` 与可访问名称。当前宿主的完整原生模态 Layer/focus scope 尚不支持；不能把视觉遮罩等同于完整的原生模态可访问性支持。
- 隐藏的视图/菜单不可继续接受点击或键盘输入。弹出菜单不能被侧栏的滚动裁剪隐藏；窄窗口与长列表需实际检查。

## 验收场景

1. 空配置窗口只显示清晰的新建入口和文件工作区，不显示无对象的编辑/删除按钮或任何配置输入表单。
2. 新建服务器为单独模态层；密码方式不显示私钥字段；错误在对话框内提示；取消后文件区布局不变化。
3. 至少两个服务器时，悬停 A 的 `…` 后编辑/删除始终作用于 A，即使当前选中 B。
4. 菜单可通过按钮开启，Escape 和外侧点击关闭；键盘焦点可以发现仅悬停显示的更多按钮。
5. 打开对话框后后台控件不能操作；关闭后可继续从原位置导航。
6. 窗口缩小时，文件区保有可用高度，对话框内部可滚动，提交按钮可访问，底部活动区不抢占整个工作台。
7. 选择文件、进入目录、上传下载、排序筛选、重命名、新建目录、队列暂停/重试和日志查看均保留原有实际功能。
